# quitos_RM

App personal para planificar y registrar rutinas de gimnasio. Es una PWA para iPhone: funciona sin conexión y guarda los datos en el teléfono.

La especificación está en `CLAUDE.md` y el diseño visual en `DISENO.md`.

## Comandos

- `npm install`: instala las librerías del proyecto.
- `npm run dev`: abre la app en modo desarrollo; los cambios se ven al instante.
- `npm run build`: arma la versión final en la carpeta `dist/`.
- `npm run preview`: muestra la versión final armada.
- `npm run lint`: revisa el código en busca de errores comunes.
